## 🎨 What's Inside?

Instead of a boring list of links, I wanted to build an immersive experience. Here are some of my favorite features you'll find while scrolling through:

- **Interactive 3D Stage**: A custom Three.js / React Three Fiber interactive MacBook scene with dynamic lighting that responds to you.
- **The Bento Grid**: A heavily interactive, glassmorphic layout that showcases my tech stack, current Spotify rotation, and a mini Tower of Hanoi simulator.
- **Dynamic Theming**: Seamless Light and Dark mode transitions built natively with Tailwind CSS and React Context.
- **Fluid Animations**: Smooth orchestrations utilizing Framer Motion and GSAP to make the UI feel alive.

---

## 🛠️ How It's Built

If you're curious about the stack, I used some of my favorite modern tools to put this together:

- **Core**: React, TypeScript, and Vite for a lightning-fast foundation.
- **Styling**: Tailwind CSS for utility-first styling, heavily leaning into glassmorphism and subtle shadows.
- **3D & Motion**: Three.js (via React Three Fiber) and Framer Motion.
- **Routing**: TanStack Router for type-safe, seamless page transitions.
